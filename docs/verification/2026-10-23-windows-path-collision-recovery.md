# Windows reviewed path-collision recovery

Installed `044e5441` exposed two different document identities at `Notes/Untitled 31.textpack`: Windows `080a76d5-f83d-456f-b893-67b869d27af2` and Mac/server `ee455de6-5640-453c-8632-7984a370688c`. Windows retained an unbased conflicted upload and a separate remote conflict. A plain rename could not resolve those operations; no owner files or journals were changed during diagnosis.

The Core command discovers the exact pair and reviews current local bytes, remote revision, account/root binding, permissions and an unoccupied identity-qualified destination. Keep both saves a prepared resolution before the existing journaled local rename, retains hash-verified original payloads and operation metadata, then atomically queues a new upload with a new operation ID. Prepared resolutions hold both identities from sync. A completed receipt means the local move and new queue entry are durable, not that remote sync has finished.

Actual-engine regression covers the retained collision before recovery, exact two-document convergence, idempotent completion, restart at prepared/moved/completed boundaries and the native move journal's prepared/moved/observed boundaries. Stale revision, changed local bytes, occupied destination, a remote local-ID tombstone, lost permission, changed account and duplicate operation IDs refuse. Prepared rows remain discoverable after the source has moved.

Validation: focused PC and Mac commands are `dotnet run --project windows/TextText.Core.Tests -- --path-collision`; Mac final run passes 24 assertions (`/private/tmp/texttext-path-collision-mac.log`). Elevated PC full Core passes 1,863 assertions (`%TEMP%/texttext-path-collision-core-full.log`, exit 0); the final focused guard delta passes 24 (`%TEMP%/texttext-path-collision-focused.log`, exit 0). The Mac focused fixture uses the physical `/private/var` temporary path, preserving the production linked-path refusal. No installed recovery or multiplayer acceptance is claimed by these tests; those require the next coordinated release and reviewed product action.
