## Platform boundary cases

- Browser transaction abort, blocked IndexedDB open/migration and synchronous IDB request exceptions apply to the browser adapter. Native stores do not use IndexedDB or expose a database migration transaction; their corresponding boundaries are atomic-file replacement/intent recovery and fail-closed checkpoint schema reads. These are covered independently, not represented as native IDB tests.
- Windows supports a checkpoint cancellation token and proves pre-cancellation leaves bytes, generation, intent and upload state unchanged. Mac materialization is a synchronous primitive with no cancellable transaction; cancellation during that primitive is not an exposed outcome. Its caller must fence a late result by lifecycle (T07), while an already-started durable write may finish.
- Native adapters have no browser-quota concept; actual filesystem ENOSPC and Windows no-space errors are verified on isolated images. The browser quota/abort tests verify its transactional acknowledgement contract and retained recovery copies; physical browser eviction remains an explicit limitation.
- Native-local success despite a failed browser copy and rejection despite a successful browser copy are separate shared-client boundary tests. Real adapter receipts verify native persistence behavior separately. Combined installed fault injection remains T04 and does not change either acknowledgement contract.
