# Browser shutdown stage diagnostics

Adds metadata-only stderr records to the existing browser driver shutdown: protocol/EOF dispatch origin, handler entry, retained refusal, context-close before/after/error and process-exit request. Records contain only fixed stage/origin, monotonic milliseconds, UTC and PID. No stdout messages, credentials, configuration, document values or raw error messages are added.

Each fixed stage/origin emits at most once (14 records total, each at most384bytes). Best-effort asynchronous `fs.write` callbacks consume write errors; synchronous invocation and clock/format failures are caught. Diagnostics are never awaited and do not wait for backpressure or callback completion. Existing process.exit behavior is preserved, so terminal records may be dropped; delivery is not guaranteed. Existing context.close await, swallowed close rejection, retained-failure refusal, exit0 and serialized message/EOF queue ordering remain intact. No timeout or force-cleanup behavior changed.
