# Content-first reference review

Reviewed September 28, 2026. These are design observations from the public pages and visible product previews, not claims about TextText performance or undocumented features.

- [Flo State](https://www.flocrivello.com/flostate/?y): the interactive preview puts a narrow note list and slim tab row beside a wide, unboxed writing surface. The title and text carry the visual weight. Keep creation and return to writing short; do not copy its branding or infer measured speed from its marketing.
- [Resurf](https://resurf.so/): the visible library leads with images in varied intrinsic proportions, small gutters, and little card furniture. Adapt this to TextText's actual assets and mixed folders while retaining readable captions and accessible selection.
- [Shiori](https://www.shiori.sh/): the public product preview shows a compact inbox list next to a clean article reader. Title and source lead; Reader/Original is easy to find, while extra reading actions stay compact. Its summary panel is a product choice, not a reason to put an AI summary above every TextText article.
- [Raindrop](https://raindrop.io/): the public hero preview shows a plain collection tree with a visual grid. Its official page documents list, grid, masonry, and headline views. Use it as a secondary reference for contextual view choice, not a second hierarchy of hardcoded destinations.
- [Pencil authentication guide](https://docs.pencil.dev/getting-started/authentication): connection options are shown with their actual provider requirements and status. Use equally honest labels for TextText's supported runtime; this page does not establish TextText auth support.
- [Paper MCP guide](https://paper.design/docs/mcp): its in-context connection and immediately visible first result are useful onboarding cues. TextText's embedded agent still requires its own authorized runtime and actual item work; external MCP connection alone cannot satisfy that journey.

Only public page previews and documentation were inspected. No authenticated reference product workspace or private screen was inspected.
