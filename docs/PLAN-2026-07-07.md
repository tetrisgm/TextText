# Plan: instant sync, subfolders, bookmarks, sharing, workspace menu

Written 2026-07-07. This is both the record of what landed and the working
queue for the Codex loop (see `codex/QUEUE.md`). Claude holds the trunk
(schema, security, contracts, merges, review, deploy); Codex builds bounded
tracks against the contracts below.

## Landed in trunk (by Claude, this commit)

- **Schema**: `folders.parent_id` (+ `path` is now the FULL slash path),
  `collaborators.invited_email` + nullable `user_id` (+ email unique
  index), `posts.capture_status` + `posts.capture` jsonb. Pushed to Neon.
- **Instant sync**: change cursor (`src/lib/sync-cursor.ts`) +
  `GET /api/sync/v1/changes?cursor&wait` long-poll; Mac `ChangeListener`
  (self-contained long-poll loop) wired in AppDelegate: remote edits and
  deletes trigger a sync pass within ~2s; the 60s timer is now a fallback.
- **Subfolders**: `createSubfolder` store core (mode inherited, depth cap
  4, race-safe paths), `POST /api/sync/v1/folders`, `createSubfolderAction`,
  MCP `create_folder`. Manifest/manifests unchanged: a subfolder IS a
  folder with a deeper path.
- **Bookmarks pipeline**: creation marks `capture_status=pending` + light
  server fetch (`src/lib/bookmark-fetch.ts`, SSRF-guarded, keepPending);
  capture agent API `GET /api/sync/v1/captures` +
  `PUT /api/sync/v1/captures/{id}` (multipart: meta/readable/screenshot/
  html; artifacts to Blob). Mac `CaptureAgent` is a wired skeleton (T3).
- **Sharing core**: `src/lib/shares.ts` (invite by email, bind-on-first-
  access, roles editor/viewer, revoke, shared-with-me), share invite email
  over MXroute SMTP, collaborator save path in `saveEditablePostAction`
  (content-only: type/status/slug/date frozen), post page grants
  view/edit via item share. Owner-only invite management.
- **MCP**: `create_folder` tool, nested paths, full spec at `docs/mcp.md`.
- **Mac open-with**: Info.plist markdown document types + `OpenFileHandler`
  skeleton (T3 fills the mapping + default-app toggle).

## Codex tracks (parallel worktrees; briefs in codex/tasks/)

- **T1 mac-nested-sync**: SyncEngine + ServerClient learn nested folder
  paths (mkdir -p, per-folder scan stays one level, new local dirs POST
  /api/sync/v1/folders). Owns those two Swift files only.
- **T2 bookmarks-web**: FolderPage bookmark cards (capture status, favicon,
  description, screenshot thumb), bookmark reader view with original/
  screenshot links, add-bookmark UX polish. Owns FolderPage.tsx + new
  components/css-modules.
- **T3 mac-capture-openwith**: fill CaptureAgent (offscreen WKWebView:
  readable extraction, original HTML, full-page PNG; multipart PUT) and
  OpenFileHandler (index lookup -> browser edit URL; NSWorkspace default
  toggle + menu item). Owns the three skeleton files.
- **T4 sharing-workspace-ui**: ShareDialog (Notion-style: email + role,
  people list, revoke, copy link), WorkspaceMenu (top-left: workspace
  name, account email, settings, invite, LOG OUT), FolderTree (nested
  sidebar with create-subfolder), SharedWithMe list. New standalone
  components only; Claude mounts them after merge.

## Invariants nobody may break

- Notes and bookmarks are unlisted FOREVER (action, store, sync, MCP).
- Collaborator saves never change type/status/slug/date/pinned.
- Capture state is owned by the capture pipeline, never by markdown
  round-trips.
- No em dashes in copy. Both color themes. DESIGN.md rules on reader
  surfaces.
